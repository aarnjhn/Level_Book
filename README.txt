AUTO LEVEL SURVEY — ICON FILES

Contents:
- icon-192.png: PWA install icon (192 x 192)
- icon-512.png: PWA install icon (512 x 512)
- apple-touch-icon.png: Apple home-screen icon (180 x 180)
- favicon-32.png and favicon-16.png: browser favicons
- auto-level-logo-original.png: original artwork

How to use:
1. Extract this ZIP.
2. Copy the PNG files into your web app's icons/ folder.
3. In manifest.webmanifest, configure icon-192.png and icon-512.png as the app icons.
4. Keep icons/ alongside index.html. Paths are case-sensitive on web hosting.
