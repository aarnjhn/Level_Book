AUTO LEVEL SURVEY — WEB APP PACKAGE

CONTENTS
- index.html: the app
- manifest.webmanifest: installable app details
- sw.js: offline cache after first online visit
- images/auto-level-logo.svg: logo (keep this folder beside index.html)
- icons/: home-screen icons

PUBLISH FREE WITH GITHUB PAGES (Android phone or computer)
1. Extract this ZIP.
2. Sign in to GitHub and create a new PUBLIC repository named auto-level-survey.
3. Upload the CONTENTS of this folder (not the outer folder). index.html must be at repository root. Keep images and icons folders.
4. Open repository Settings > Pages. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
5. Wait for deployment. Your site URL will look like https://YOUR-USERNAME.github.io/auto-level-survey/
6. Open that HTTPS link in Chrome on Android, then Chrome menu (⋮) > Add to Home screen / Install app.

OFFLINE & SAVED DATA
- Open the site online once first so the app files can be cached. It can then load offline.
- Saved surveys use browser storage on that device/browser. They are NOT synced to the cloud or automatically shared with other devices. Export backups regularly.
- Do not rename or separate index.html from the images and icons folders.
